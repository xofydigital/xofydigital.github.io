HappVPN Account and Data Deletion

Last updated: July 31, 2026.

This page allows HappVPN users to request deletion of their account and associated data without reinstalling the application.

The current HappVPN version does not create a username-and-password account. Access, trial usage, subscriptions, and payments are linked to a pseudonymous application installation identifier. A request submitted using the instructions below applies to this backend record and its associated data.

How to submit a request

  1. Create a new message in any email application.
  2. Send it to: happvpnapp@gmail.com.
  3. Use the subject: HappVPN account deletion.
  4. Include the statement: “Please delete my HappVPN account and associated data.”
  5. If you made a payment, include the payment provider, approximate payment date, and transaction identifier shown on your receipt. This helps locate the associated record and verify the request.
  6. Send the message and wait for a response from support.

Do not send a password, full payment card number, CVC/CVV code, banking confirmation code, cryptocurrency wallet private key, or Play Integrity token. HappVPN never requests this information for data deletion.

Request verification

To protect data against deletion by an unauthorized person, support may request additional information needed to locate the record and verify the connection to it. Only the minimum information necessary for this purpose will be requested.

Data that will be deleted

After verification, HappVPN will delete or de-identify:

  • the pseudonymous device identifier;
  • the backend access and subscription record;
  • trial usage records;
  • the legacy subscription link, if a migration was performed;
  • operational payment and receipt records when continued retention is not legally required;
  • other data directly associated with the located HappVPN record.

Data that may be retained

Certain payment, fiscal, fraud-prevention, and request-completion records may be retained for a period required by applicable law or necessary to protect legitimate interests. Such data is not used for advertising and is deleted when the required retention period ends.

A deletion request sent to HappVPN does not delete data independently retained by Google, YooKassa, Heleket, a bank, or another independent provider under its own policies. Contact the relevant provider directly to request deletion of that data.

Local data on the device

A backend request cannot remove files, preferences, and logs that exist only on the device. To remove local data, clear HappVPN application data in Android settings or uninstall the application.

Processing time

Once all information required to verify the request has been received, deletion is normally completed within 30 calendar days. If applicable law requires a different period or some data must be temporarily retained, support will explain this in its response.

Consequences of deletion

After deletion, the backend record, remaining access period, trial history, or link to a previous subscription may not be recoverable. If a subscription is still active, state this in the message before confirming deletion.

Deletion contact

Email address for account and data deletion requests: happvpnapp@gmail.com.
